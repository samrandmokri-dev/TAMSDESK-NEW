# TAMSDESK

نرم‌افزار دسکتاپ از راه دور (Remote Desktop) شبیه AnyDesk، برای ویندوز، که روی بستر
اینترنت کار می‌کند. اتصال بر پایه‌ی **رضایت صریح** است: کامپیوتر میزبان یک **شناسه (ID)**
و یک **رمز یک‌بارمصرف** نشان می‌دهد، و هر اتصال ورودی باید روی خود میزبان تأیید شود —
دقیقاً مثل AnyDesk.

> این نسخه‌ی ۱ (v1) هسته‌ی کامل و کارآمد را دارد: مشاهده‌ی صفحه + کنترل کامل ماوس و
> کیبورد از راه دور، از طریق یک سرور رله روی اینترنت. در پایین این فایل فهرست قابلیت‌هایی
> که هست و قابلیت‌هایی که برای تکمیل باقی مانده آمده است.

---

## اجزای پروژه

```
TamsDesk/
├─ relay-server/          ← سرور رله (Node.js) که روی VPS اجرا می‌شود
│  ├─ server.js
│  └─ package.json
└─ TamsDesk.Client/       ← برنامه‌ی ویندوز (C# / WPF) — خروجی TamsDesk.exe
   ├─ TamsDesk.Client.csproj
   ├─ Config.cs           ← آدرس سرور رله را اینجا تنظیم کنید
   ├─ MainWindow.xaml(.cs)      ← صفحه‌ی اصلی: هم میزبان هم کنترل‌کننده
   ├─ RemoteWindow.xaml(.cs)    ← پنجره‌ی نمایش صفحه‌ی راه دور
   ├─ Capture/ScreenCapturer.cs ← گرفتن تصویر صفحه (GDI + JPEG)
   ├─ Input/InputInjector.cs    ← تزریق ماوس و کیبورد (SendInput)
   ├─ Signaling/RelayClient.cs  ← اتصال WebSocket به رله
   └─ Protocol/Messages.cs      ← قالب پیام‌ها
```

معماری: دو کلاینت TAMSDESK هیچ‌وقت مستقیم به هم وصل نمی‌شوند؛ هر دو به سرور رله وصل
می‌شوند و رله پیام‌ها را بر اساس ID بین آن‌ها رد و بدل می‌کند. به همین دلیل اتصال از پشت
NAT و روی اینترنت بدون باز کردن پورت کار می‌کند.

```
میزبان  ⇄  سرور رله (VPS, wss)  ⇄  کنترل‌کننده
```

## ۱) اجرای سرور رله روی VPS

نیازمند Node.js نسخه‌ی ۱۸ به بالا.

```bash
cd relay-server
npm install
PORT=8080 node server.js
```

**حتماً پشت TLS قرار دهید** تا کلاینت‌ها با `wss://` وصل شوند (ویندوز اتصال رمزنگاری‌نشده
را محدود می‌کند). ساده‌ترین راه، Caddy:

```
# /etc/caddy/Caddyfile
relay.yourdomain.com {
    reverse_proxy 127.0.0.1:8080
}
```

سپس آدرس شما می‌شود: `wss://relay.yourdomain.com`

برای همیشه‌روشن بودن، سرویس را با `pm2` یا `systemd` اجرا کنید:

```bash
npm i -g pm2
pm2 start server.js --name tamsdesk-relay
pm2 save
```

## ۲) ساخت فایل EXE روی ویندوز

> توجه: ساخت EXE ویندوزی فقط روی **ویندوز** انجام می‌شود (نه لینوکس). این محیطی که
> پروژه در آن نوشته شد لینوکس بود و SDK دat‌نت هم نداشت، به همین دلیل خودِ EXE اینجا
> کامپایل نشد؛ شما با یک دستور زیر آن را می‌سازید.

۱. [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0) را روی ویندوز نصب کنید.

۲. آدرس رله را در `TamsDesk.Client/Config.cs` تنظیم کنید:

```csharp
public static string RelayUrl { get; set; } = "wss://relay.yourdomain.com";
```

۳. در پوشه‌ی `TamsDesk.Client` این دستور را بزنید:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

فایل خروجی اینجاست:

```
TamsDesk.Client\bin\Release\net8.0-windows\win-x64\publish\TamsDesk.exe
```

این یک فایل تک‌پارچه و خوداتکا (self-contained) است؛ روی ویندوزی که دات‌نت نصب ندارد
هم اجرا می‌شود. برای اجرای ساده‌تر بدون self-contained، `--self-contained false` بزنید.

## ۳) نحوه‌ی استفاده

**روی کامپیوتری که می‌خواهید کنترل شود (میزبان):**
1. `TamsDesk.exe` را باز کنید.
2. روی **Allow incoming connections** بزنید. یک **ID** و یک **Password** نمایش داده می‌شود.
3. این دو را به شخص مقابل بدهید.
4. وقتی کسی وصل شود، یک پیام تأیید باز می‌شود؛ تا شما **Yes** نزنید، صفحه به اشتراک
   گذاشته نمی‌شود.

**روی کامپیوتری که کنترل می‌کند:**
1. `TamsDesk.exe` را باز کنید.
2. در بخش **Remote computer**، ID و Password طرف مقابل را وارد کنید.
3. **Connect** را بزنید. بعد از تأیید میزبان، صفحه‌ی او را می‌بینید و با ماوس و کیبورد
   کنترل می‌کنید.

## مدل امنیت و رضایت

- هر اتصال ورودی نیازمند **رمز یک‌بارمصرف** و **تأیید دستی** روی خود میزبان است.
- رمز را رله نمی‌بیند؛ اعتبارسنجی رمز روی میزبان انجام می‌شود.
- رله هیچ ترافیکی را ذخیره نمی‌کند، فقط رد و بدل می‌کند.
- برنامه مخفی اجرا نمی‌شود و رابط کاربری همیشه دیده می‌شود.

**مهم:** این ابزار برای پشتیبانی و دسترسی قانونی و با رضایت طرف مقابل است. استفاده برای
دسترسی مخفیانه یا بدون اجازه به کامپیوتر دیگران غیرقانونی است.

## قابلیت‌های موجود در v1

- ✅ کار روی اینترنت از طریق سرور رله (بدون نیاز به باز کردن پورت)
- ✅ شناسه + رمز یک‌بارمصرف + تأیید دستی اتصال
- ✅ مشاهده‌ی زنده‌ی صفحه (JPEG، قابل تنظیم کیفیت/نرخ فریم)
- ✅ کنترل کامل ماوس (حرکت، کلیک چپ/راست/وسط، اسکرول)
- ✅ کنترل کیبورد
- ✅ نمایش نشانگر ماوس میزبان
- ✅ خروجی تک‌فایل EXE

## نقشه‌ی راه برای رسیدن به «همه‌ی قابلیت‌های AnyDesk»

این موارد عمداً در v1 نیستند و گام‌های بعدی هستند:

- ⏳ انتقال فایل (File transfer) و کلیپ‌بورد مشترک
- ⏳ چند مانیتور و انتخاب مانیتور
- ⏳ فشرده‌سازی ویدیویی واقعی (H.264/VP8) به‌جای JPEG، برای سرعت و مصرف پهنای باند بهتر
- ⏳ اتصال مستقیم P2P با WebRTC/STUN/TURN (رله فقط هنگام نیاز)
- ⏳ دفترچه‌ی مخاطبین، رمز دائم و اتصال بدون تأیید (Unattended access)
- ⏳ چت متنی و صدا
- ⏳ رمزنگاری سرتاسری (end-to-end) مستقل از TLS رله
- ⏳ نصب‌کننده (installer) و اجرای به‌صورت سرویس ویندوز
- ⏳ ضبط جلسه، قفل کیبورد/ماوس میزبان، تنظیم کیفیت خودکار

اگر بخواهید، هرکدام از این موارد را در گام بعد اضافه می‌کنم.
